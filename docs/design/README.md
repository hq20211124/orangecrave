- **定位**：独立系统 · 本机运行 · 演示与学习
- **状态**：设计定稿 · 桩契约已定 · **v1 实现完成**（后端 13 模块 + 原生前端 + 小程序演示版）

## 三处需要业务方确认

设计中没有擅自填充，留待确认：

1. **分享码未核销部分的退款口径** —— 取决于 `freeShareConfig` 中的价格档位（服务端配置），设计为可配置规则，默认按「退未核销余额」实现
2. **团长 / 摊主身份认证的审核标准** —— 代码中只有流程片段，具体材料要求未知
3. **VIP 会员的获取方式** —— 充值还是消费额自动升级，代码无法判定

## 设计中被证据推翻的几处

初版方案经推敲后修正，记录在此以免重复踩坑：

| 初版判断 | 核实结果 |
|---|---|
| 发票二期再做 | **已上线功能**，必须进 v1 |
| 定价用数量阶梯 | 实际是**按面积计费** |
| 退款规则「审核前可全额退」 | 实际是**付款后 4 小时窗口** |
| 用户举报下架 | 小程序**无此入口** |
| 订单超时用 `@Scheduled` 全表扫描 | 业界用 **DelayQueue + 启动重建** |
| 「分享」属 UGC 审核 | 实际是**订单模式**（付款方 ≠ 收货方） |
